# TrailMate - Frontend (Angular)

TrailMate is a full-stack travel planning web application where users can explore trips, create itineraries, and manage personalized travel plans.

## 🚀 Tech Stack
- Angular
- TypeScript
- HTML / CSS
- REST API Integration

## ✨ Features
- User Signup & Login
- JWT-based Authentication
- Create and manage travel itineraries
- View user-specific saved trips
- Responsive UI
